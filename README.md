# C++ Linked List Implementations

A Data Structures & Algorithms learning project focused on implementing and understanding linked lists in C++.

## About the Project

This project explores three fundamental linked-list data structures: singly linked lists, doubly linked lists, and circular linked lists. It also applies linked-list concepts to practical programming problems.

The goal is to strengthen my understanding of pointers, dynamic memory allocation, node manipulation, traversal, and algorithmic problem-solving.

## Features

### Singly Linked List
- Insert nodes at the beginning, end, and after a specific value
- Delete nodes from the beginning, end, and by value
- Display the list in reverse order without modifying it
- Reverse the linked list
- Remove duplicate values
- Detect loops using Floyd's cycle-detection algorithm
- Find the middle node
- Separate even and odd values
- Reverse the two halves separately
- Swap consecutive nodes

### Doubly Linked List
- Insert and delete nodes at different positions
- Swap nodes by updating links
- Reverse a sequence of nodes
- Navigate a playlist forward and backward
- Manage hierarchical store inventory
- Rearrange cinema seating nodes

### Circular Linked List
- Insert and delete nodes
- Traverse and display the circular list
- Solve the Josephus problem
- Implement a round-robin task scheduler

## Concepts Practiced

- Structures and pointers in C++
- Dynamic memory allocation using `new` and `delete`
- Passing pointers by reference
- Singly, doubly, and circular linked lists
- Pointer manipulation and edge-case handling
- Recursion and iterative algorithms
- Searching, traversal, and node deletion
- Basic problem-solving with data structures

## How to Run

1. Clone or download this repository.
2. Open the project folder in your C++ IDE, or open a terminal in that folder.
3. Compile the source file using a C++ compiler.

Using g++:

```bash
g++ -std=c++11 main.cpp -o linked_list_demo
```

Run on Windows:

```bash
linked_list_demo.exe
```

Run on Linux or macOS:

```bash
./linked_list_demo
```
